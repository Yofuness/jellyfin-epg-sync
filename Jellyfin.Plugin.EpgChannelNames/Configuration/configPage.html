Dispatcharr

Create one in Dispatcharr for your user. Required: without Dispatcharr the plugin does nothing (unless an advanced EPG-only filter is set).

Features

"Live NHL Ice Hockey" becomes "Live NHL Hockey: Flyers vs Avalanche" when the description names the teams. NHL, NFL, NBA, MLB, MLS, major UK/EU soccer and rugby, GAA, cricket (Test Cricket: South Africa vs Australia · Day 3) and F1 (F1: United States GP 2018). Team list from ESPN, refreshed monthly.
Games where both teams are known get a card with both team logos and the league logo (from ESPN). Real program images are never replaced.
Makes Programs-page cards recognizable. Real program images are never replaced.
Removes the airing placeholder (which only plays a logo) so it doesn't show on the Programs page. Later blocks stay, so a game added later still gets a program. The channel itself stays.
When a channel airs the same show in back-to-back blocks ("Live Tennis" at 4:00 and 5:00), only the first block gets a card in the Programs page rows. The later blocks stay in the Guide. Off = every block gets its own card.

Programs page rows

Jellyfin's Programs page shows rows (Shows, Movies, Sports, News, Kids). Each Dispatcharr group's programs go into one row, picked from the group name. Change any group below.
