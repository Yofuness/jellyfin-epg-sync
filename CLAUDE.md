# CLAUDE.md

Jellyfin 12 plugin (C#, net10.0) that renames Live TV channels to the EPG program currently airing. Built for Dispatcharr channels like `NHL GAME 01 Team A vs Team B`.

## Build
- No local .NET SDK. Build only with Docker: `./build.sh [version] [repo-base-url]`
- Output: `Jellyfin.Plugin.EpgChannelNames/bin/Release/net10.0/*.dll`, plus `dist/` zip and `manifest.json`
- `build.sh` runs as the host user. If `bin/` or `obj/` end up root-owned, remove them through a container, e.g. `docker run --rm -v "$PWD/Jellyfin.Plugin.EpgChannelNames":/src alpine rm -rf /src/bin /src/obj`

## Releases
- The release workflow commits `manifest.json` to `main` as github-actions[bot] after every release. Always `git fetch` and rebase on `origin/main` before pushing.
`.github/workflows/release.yml` runs when a GitHub release is published. It turns the tag (`v1.2.3`) into a 4-part version, runs `./test.sh`, then `./build.sh`, and uploads `dist/*` to the release. The plugin repository URL is `https://raw.githubusercontent.com/Yofuness/jellyfin-epg-sync/main/manifest.json`: root `manifest.json`, all versions newest-first. The last workflow step merges the release's manifest into it with `scripts/merge-manifest.py` (same version replaces, otherwise prepends) and pushes to `main` as github-actions[bot], only after the zip upload succeeds. The old `releases/latest/download/manifest.json` still works but 404s for about 2 min after each release while the build runs. v1.0.0 is deliberately absent (built against 10.11.11; fails to load on older 10.11). Under `act` the push step is skipped; "Check manifest merge" runs on a temp copy.
Test it locally with `act` (the upload step is skipped when `ACT` is set). `--bind` is required because the scripts start Docker containers that mount the repo:
`echo '{"action":"published","release":{"tag_name":"v1.0.0"}}' > /tmp/ev.json && act release -e /tmp/ev.json --bind -P ubuntu-latest=catthehacker/ubuntu:act-latest`

## Layout
- `Dispatcharr/`: `IDispatcharrClient.GetChannelsAsync` → `DispatcharrChannel(Number, Name, Group, StreamName)`. 3 requests with `X-API-Key`: `GET api/channels/channels/` (unpaginated array; `channel_number` float like `220.0`, `channel_group_id`, `streams` ids in priority order), `GET api/channels/groups/` (~1700 groups, unpaginated), `POST api/channels/streams/by-ids/ {"ids":[...]}` for the first stream of each channel. Sent with Content-Length (`StringContent`); the fake server needs it. Number formatted like M3U `tvg-chno` (`220`). Group names normalized (`NormalizeGroupName`): the provider's NHL group contains U+00A0.
- `ChannelRenamer.cs`: core logic. Per Jellyfin channel: Dispatcharr event channel (`ParseEvent` on the stream name) → rename + `ApplyEventProgramsAsync`; other Dispatcharr channel → `ApplyCategoryAsync` only (never renamed); not in Dispatcharr + filter matches → EPG-only rename.
- `CategoryRules.cs`: `Resolve(group, AutoGroupCategories)`: a rule wins (`= None` = no row), else `Guess` from group-name keywords (Kids, News checked before Sports, Movies, Shows). Parses `group = Shows|Movies|Sports|News|Kids|None` and applies a category reversibly. Shows=`IsSeries`, Movies=`IsMovie`, others=tags. What the plugin set is recorded in `program.ProviderIds["EpgChannelNames.Category"]` (`series`, `movie`, `tag:X`), so removing or changing a rule undoes exactly that and never EPG-provided flags.
- `RenameChannelsTask.cs`: scheduled task (startup + interval). Key `EpgChannelNamesRename`.
- `Teams/`: team database. `League.All` (keys, title labels, ESPN paths, keywords; GAA is a built-in county list). `TeamDatabase` downloads `site.api.espn.com/apis/site/v2/sports/{sport}/{league}/teams` (no key) into `DataFolderPath/teams.json`; `GetTeamsAsync` uses the cache and downloads only when there is none (retry at most hourly); `RefreshTeamsTask` (key `EpgChannelNamesRefreshTeams`, every 30 days) refreshes, a failing league keeps its cached teams. `TeamMatcher.BuildTitle` is pure. TheSportsDB was rejected: its free key ignores the league id and rate-limits (429).
- `GuideRefreshListener.cs`: reruns the task when Jellyfin's `RefreshGuide` task completes.
- `ServiceRegistrator.cs`: DI registration.
- `Api/GroupsController.cs`: `GET /EpgChannelNames/Groups` (admin only, `RequiresElevation`) returns Dispatcharr groups with channel count and guessed row for the config page's group table. Needs `<FrameworkReference Include="Microsoft.AspNetCore.App" />`. The page stores table choices as ordinary lines in `GroupCategoryRules`; lines for groups not in the table stay in the Custom rules box.
- `Configuration/`: settings class + embedded `configPage.html`. Plugin GUID `4f1c7a3e-6b2d-4e8a-9c51-0d7e2a9b3f64` (keep in sync with `Plugin.cs`, the config page, and `build.sh`).

## Key behavior (non-obvious)
- v2 model: event channels are detected from the stream name with `EventRegex` (`prefix : title / …`). Empty title = nothing on now, with no EPG fallback (Dispatcharr's EPG for these is a placeholder repeating the channel name). `{prefix}` is the full stream part before ":" (`CA - NHL GAME 01`), per the user's choice to keep country codes.
- `ChannelNameRegex` is an optional filter (empty = all). It is required only in EPG-only mode (no Dispatcharr, or channel not listed). `Plugin` ctor clears the v1 defaults `NHL GAME \d+` / `^NHL GAME \d+` once (`IsOldDefaultRegex`).
- Stale events (`EventTime`, `StaleEventHours` default 6): the start time is read from the event title (`MON DD – H:MM AM/PM ET|UK`, the provider's only format; year = closest to now; ET fixed UTC-5, UK UTC+0). Events that started more than N hours ago count as "nothing on" (the provider leaves finished GAATV matches in stream names for days). Undated titles are never stale. Unit tests with fixed real dates run with `StaleEventHours = 0` (set in the test constructor) so they don't break once those dates pass; the integration test uses an undated fake game ("TONIGHT") plus a relative-date stale GAATV event.
- Program images (`UseChannelLogo`, default on): programs without their own image get the channel logo's local file (`ApplyChannelLogo`, tracked in `ProviderIds["EpgChannelNames.Logo"]`, real images never replaced). Jellyfin gotchas, verified in its 10.11 source and still true in 12: (1) updating an existing item does NOT persist `ImageInfos` (`Attach(...).State = Modified` only writes the row); (2) `ILibraryManager.UpdateImagesAsync` returns early for non-library items (`SourceType != Library`, i.e. all Live TV). So images are written with `IItemPersistenceService.SaveImagesAsync(program)` (12.x; it was `IItemRepository.SaveImages` in 10.11). Channel logos may be stored as remote URLs (seen in the test, not on the user's server); `EnsureLocalChannelLogoAsync` calls `ConvertImageToLocal(channel, logo, 0, removeOnFailure: false)`, which throws `InvalidOperationException` when all URLs fail (caught).
- Placeholders are never categorized (`IsPlaceholder`): program title equals the channel's own name (Jellyfin original, Dispatcharr name or stream name), ignoring HD/FHD/SD/HEVC/UHD/4K/◉/², or the title is in `IgnoredProgramTitles` (default "Channel No Longer Available"). On the user's server ~half of all airing programs are such placeholders (88 channels have no real guide); v2.0.0 tagged them, flooding the Sports section with ~1300 programs. `Apply(null)` on them also undoes those tags.
- Category rules apply to every real program in the window on regular channels, and to the airing block only on event channels (events with no rule default to Sports). Unknown rule groups are warned about with the list of real groups.
- Matchup images (`UseMatchupImages`, default on): `TeamMatcher.Match` gives both teams (regular channels: EPG title + description; event channels: the event title, airing block only). `Teams/MatchupImages` downloads ESPN logos to `DataFolderPath/logos/` (keyed by URL hash), draws a 960x540 card with SkiaSharp (league logo on top from `League.Logo`, ESPN dark variants; rugby and cricket get ESPN sport icons; none for GAA; logo | divider | logo; no text, servers may have no fonts) into `DataFolderPath/matchups/`, removed after 30 days unused. SkiaSharp 3.119.4 is referenced with `ExcludeAssets=runtime`: Jellyfin 12.0 (and 12.2) ships that exact version; tests add `SkiaSharp.NativeAssets.Linux.NoDependencies`. Image choice in `ApplyImage`: EPG image > matchup > channel logo, all tracked by the `EpgChannelNames.Logo` key. GAA counties have no logos; cricket nations use ESPN cricket logos by team id (no league logo: internationals have no league; none for Nepal).
- Repeats (`HideRepeatedPrograms`, default on; `IsRepeat`): on regular channels, programs are walked by start time; a block with the same (final) title starting within 1 min of the previous block's end gets `CategoryRules.Apply(null)`, so only the first block has a row card. When it ends, the next block is first in the window and gets the tags. Flags set by the EPG itself can't be removed (Apply only undoes its own).
- Cricket and F1: cricket is a built-in league (`League.BuiltInTeams`, nations, `KeywordRequired` "Cricket") with its own label (`Test/ODI/T20 Cricket`, ` · Day N`, no "Live"). F1 is `Teams/MotorsportMatcher` (needs Formula 1/F1 in the text; GP name = up to 3 capitalized words before "Grand Prix", title first; year only if not `DateTime.UtcNow.Year`; session from title or first sentence only). `ApplyTeamTitle` tries Motorsport first. Tennis EPG has no players: not handled.
- Team titles (`UseTeamNames`, default on; `ApplyTeamTitle`, regular Dispatcharr channels only, never placeholders or event channels): `TeamMatcher` finds team names whole-word, accent- and case-insensitive, longest first, in title + description. Renames only when exactly 2 teams of one league are found; the league named in the text wins, else the first in `League.All` (domestic first). Format `{Live }{Label}: {A} vs {B}` (labels include the sport: "NHL Hockey", "Championship Soccer"; GAA adds Hurling/Football from the text), order as written. A program needs a league keyword in its text or to be sports (rule Sports or `IsSports`). Weak aliases (US cities) count only when the league is named, and are dropped when shared ("New York"). MLS and GAA need their keyword (city names / common words). The EPG title is kept in `ProviderIds["EpgChannelNames.TitleOriginal"]`, the set one in `TitleApplied`; a different Name means a guide refresh wrote a new EPG title. `TeamDatabaseUrl` (config only, not on the page) points the integration test at the fake server's `/espn/`.
- Game block (`IsEventBlock`, v2.10): the block covering the event's start time (`EventTime.ParseStartUtc`) gets the game, so tonight's games are listed hours early (upcoming = Record in the web UI); after the start, the airing block. Undated events: airing block only. `EventTime` uses real zones (America/New_York, Europe/London, DST-aware; fixed -5/0 fallback). The rule below ("only the block airing now") applies to undated events.
- Programs on Dispatcharr-listed channels (`ChannelRenamer.ApplyProgramsAsync`, window now to now+`ProgramWindowHours`): only the block **airing now** (`IsAiring`: start <= now < end) gets the game title, `GameProgramTags` and the full stream name as `Overview`. Every later block becomes a plain untagged placeholder (`NoProgramTemplate` name, empty overview, game tags stripped), so the Sports row lists only watchable games (later blocks only offer Record in the web UI). The next block gets the game within one run (15 min) of starting. Real-EPG programs are never touched.
- No game (`RemoveNoGamePrograms`, default on): only the **airing** placeholder is deleted (`DeleteItem` with `DeleteFileLocation=false, DeleteFromExternalProvider=false, notifyParentItem=false`, as in Jellyfin's `GuideManager.CleanDatabase`). Later blocks are kept, so a game the provider adds later still has a block to rename. Guide refresh re-adds deleted ones; the post-refresh run deletes again.
- `GameProgramTags` default `Live,Sports`. Jellyfin derives `IsLive`/`IsSports` from `Tags`. `Live` is +1 in the "On Now" ranking (`LiveTvManager.GetRecommendationScore`; a favorite channel is +3, per user only). `Sports` lists the program in the web Programs page's Sports row. The web client asks for 12 per row.
- If Dispatcharr goes down, channels keep their last names; after the next guide refresh they show the raw tuner names until Dispatcharr is back (unless a filter enables EPG-only mode). The integration test asserts this.
- Every run logs a summary ("Checked N channels: X from Dispatcharr, E event channels (L with an event now, S stale ignored), M EPG-mode; R renamed; programs: U updated, D removed, C categorized, T retitled with teams, P placeholders skipped").
- Dispatcharr errors (HTTP, JSON, bad URL, timeout) are logged as warnings and never fail the task.
- Jellyfin resets channel names to the M3U name on every guide refresh. The plugin stores `EpgChannelNames.Original` and `EpgChannelNames.Applied` in `channel.ProviderIds`. Any name different from `Applied` counts as a fresh original.
- The filter regex matches against the original name, never the renamed one.
- Target ABI 12.0 (v3.0.0+). `Jellyfin.Controller`/`Jellyfin.Model` are pinned to 12.0.0, the oldest 12.x; building against a newer one (e.g. 12.2.0) fails to load on older servers, as seen in 10.11 ("Could not load MediaBrowser.Common, Version=10.11.11.0"). Never use a wildcard. 10.11 support ended with v2.12.0 (net9.0, ABI 10.11.0.0); those versions stay in `manifest.json` for 10.11 servers.

## Testing
- `./test.sh`: unit tests (xUnit + Moq) in `Jellyfin.Plugin.EpgChannelNames.Tests/`, about 30 s. Run after every change.
- Never name a test.sh variable `GROUPS` (bash builtin; assignments are ignored).
- `./test.sh --integration`: also boots `jellyfin/jellyfin:12.0` (override with `JF_IMAGE=jellyfin/jellyfin:12.2`) in Docker with a fake M3U + XMLTV, checks the rename, swaps the game, then switches to a fake Dispatcharr (`scripts/fake_dispatcharr.py`: GET channels/groups, POST by-ids, real 0.32 shapes) with NHL, TNT, History and CBC channels, and checks names, the groups endpoint, the Sports and Shows rows (exact web-client row queries), rule removal, and Dispatcharr-down behavior. Phase 1 uses filter `NHL GAME \d\d` because `\d+` would be migrated away. `expect` retries for 30 s because the rename task is queued after guide refreshes. About 2 min.
- `KEEP=1 ./test.sh --integration` leaves the Jellyfin and fake Dispatcharr containers and the temp dir for inspection (remove them afterwards; the temp dir is root-owned, delete via a container).
- Tests inject config through the internal `ChannelRenamer(libraryManager, logger, dispatcharr, getConfig)` constructor and set the static `BaseItem.LibraryManager` to a mock, so the test class runs in one serial collection.
- Name templating lives in the pure `ChannelRenamer.BuildName`. Test new tokens there.
- Jellyfin caches XMLTV in `/cache/xmltv`. The integration test clears it before the second refresh.

## Code standards
Jellyfin has no written C# style guide. We follow the official plugin template (github.com/jellyfin/jellyfin-plugin-template), which the build enforces:
- `.editorconfig` and `Directory.Build.props` are copied unchanged from the template. Don't edit the style rules.
- `TreatWarningsAsErrors` + `AnalysisMode=AllEnabledByDefault` + StyleCop, Serilog and Multithreading analyzers. The build must stay at 0 warnings.
- Every public member needs an XML doc comment (`<inheritdoc />` for interface/override members). Property summaries start with "Gets or sets".
- Fix analyzer findings instead of suppressing them. Any `#pragma warning disable` or `NoWarn` needs a comment explaining why.
- Version lives in `Directory.Build.props`. `build.sh` overrides it per release.
